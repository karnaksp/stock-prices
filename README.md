# Stock Prices

Stock Prices генерирует стильные MP4-видео с анимированными графиками по тикерам. Проект можно запускать из CLI, через Python API или как постоянно работающего Telegram-бота в Docker.

## Единый вход в документацию

Основная документация находится в [docs/index.md](docs/index.md). Локально красивую версию сайта можно открыть через MkDocs:

```bash
python -m mkdocs serve
```

После запуска откройте `http://127.0.0.1:8000`.

Ветки разработки:

- `develop` - интеграционная ветка для рабочих улучшений и проверок.
- `main` - стабильная ветка, из которой публикуется GitHub Pages.

CI запускается для `main`, `develop` и pull request в эти ветки. GitHub Pages публикуется автоматически через workflow `.github/workflows/pages.yml` только при push в `main`.

## Быстрый запуск в Docker

1. Создайте `.env` в корне проекта:

```env
TELEGRAM_BOT_TOKEN=<botfather-token>
STOCK_PRICES_DEFAULT_ENGINE=stock
STOCK_PRICES_DEFAULT_MARKET=shares
STOCK_PRICES_CURRENCY=RUB
STOCK_PRICES_DURATION=30
STOCK_PRICES_FPS=20
STOCK_PRICES_THEME=default
STOCK_PRICES_OUTPUT_DIR=animations
STOCK_PRICES_RETENTION_DAYS=0
```

2. Запустите контейнер:

```bash
docker compose up -d --build
```

3. Проверьте состояние:

```bash
docker compose ps
docker compose logs -f stock-prices-bot
```

## Локальный CLI

Установка в режиме разработки:

```bash
pip install -e .
```

Российская акция:

```bash
stock-prices --tickers LKOH --start_date 2015-01-01 --end_date 2026-05-26 --currency RUB --duration 20 --fps 20
```

Глобальный инструмент:

```bash
stock-prices --tickers "AAPL|global|shares" --start_date 2015-01-01 --end_date 2026-05-26 --currency USD
```

Формат тикера:

```text
TICKER
TICKER|ENGINE|MARKET
```

Если указан только `TICKER`, используется рынок по умолчанию: `stock|shares`.

## Telegram-бот

Бот использует тот же pipeline, что CLI: загружает данные, готовит датасет, рендерит MP4 и отправляет ролик обратно в чат. Команды `/start`, `/menu` и `/меню` открывают единое кнопочное меню: помощь по синтаксису, прямые кнопки топовых shorts-сценариев, полный пакет shorts, идеи, проверенные примеры, пакет для Пульса, пакеты сценариев, draft-прогоны, случайный шортс, случайный draft и статус очереди. Если нужен привычный slash-вход, отправьте `/shorts SBER LKOH за год` или `/draft metals`: бот сам добавит режим `shorts` или `draft` к обычному запросу и поставит задачу в очередь. Команды `top drafts` и `топ черновики` ставят в очередь быстрые draft-прогоны только топовых сценариев из меню. Команды `top shorts` и `топ шортсы` ставят в очередь эти же сценарии полноценными shorts-роликами. Команды `top shorts studio`, `top shorts aurora` и `топ шортсы студио` ставят ту же top-серию в выбранной теме без ручного дописывания `theme=` к каждому preset. Команды `все шортсы`, `/all_shorts` и `all shorts` ставят в очередь полноценные shorts-ролики по всей текущей библиотеке preset-сценариев, а `все шортсы студио`, `все шортсы аурора` и `all shorts aurora` запускают тот же полный выпуск в единой теме. Команда `/pack` или `пакет пульса` показывает компактный набор по top-сценариям: команду для шортса, черновика и поста без рендера, а также кнопки `Top Studio`, `Top Aurora`, `Все шортсы`, `Все Studio` и `Все Aurora`. Команды `/kits` и `пакеты` открывают кнопочный список всех публикационных пакетов preset-сценариев без рендера. Команда `/ideas` показывает готовые сценарии для Пульса с русскими кнопками запуска, а `/examples` показывает проверенные запросы по рынкам с кнопками запуска. Команды `/posts` и `посты` показывают кнопки готовых текстовых пакетов для Пульса без запуска рендера. Команды `/music` и `/covers` показывают монтажные референсы и короткие тексты для обложек без запуска рендера. Команды `post metals`, `пост металлы` и `post LKOH SBER 2020 2024` показывают текстовый пакет для Пульса без запуска рендера: для preset-сценариев ручной пакет, для произвольного запроса skeleton по фактическим параметрам. Команды `случайный шортс`, `random shorts` и `/random_shorts` выбирают один проверенный preset и сразу ставят полноценный shorts-ролик в очередь. Команды `случайный черновик`, `random draft` и `/random_draft` выбирают один из проверенных preset-сценариев и ставят короткий draft в очередь без LLM. Несколько запросов можно отправить одним сообщением: бот поставит каждую непустую строку отдельной задачей. После постановки задачи бот показывает кнопку `Статус очереди`; команды `/queue`, `/status` и `очередь` делают то же текстом: показывают активный job, ожидающие job id и счетчики завершений/ошибок. Перед рендером бот показывает тему, метрику, валюту, градиент и инвестиционные параметры. После любого MP4 бот отправляет черновик текста для Пульса. Для preset-сценариев это ручной хук, описание, тексты для обложки, хэштеги, музыкальное/монтажное настроение и конкретные треки-референсы с пометкой про проверку прав; для custom-запросов - готовый skeleton с заголовком, хуком, вариантами обложки, фактическими параметрами, вопросом для обсуждения и монтажным настроением. После preset- и custom-видео появляются follow-up кнопки: быстрый черновик 4s, полноценный шортс 16s, вариант 12s, Aurora и Studio без повторного ввода запроса.

Команда `kit metals` или `пакет металлы` открывает публикационный пакет одного preset без немедленного рендера: хук, варианты обложки, музыкальные референсы и кнопки для шортса, черновика, всех тем, версии 12s, поста и очереди. Если не помните имя preset, отправьте `/kits` или `пакеты` и выберите сценарий кнопкой.

## Python API

```python
from datetime import date

from stock_prices import RenderSettings, TickerSpec, VideoRequest, generate_video

path = generate_video(
    VideoRequest(
        ticker_specs=[TickerSpec("LKOH")],
        render=RenderSettings(
            start_date=date(2015, 1, 1),
            end_date=date(2026, 5, 26),
            duration=20,
            fps=20,
        ),
    )
)
print(path)
```
