# Как писать запросы в Telegram

Бот не придумывает идеи сам и не использует LLM. Он принимает короткий текстовый запрос, ставит генерацию в очередь, загружает данные, рендерит MP4 и отправляет видео обратно в чат.

## Самый короткий путь к шортсу

| Хочу | Отправить или нажать |
| --- | --- |
| Выбрать готовую историю | `/shorts` или кнопка `Истории` |
| Снять свой шортс | `/shorts SBER LKOH за год` |
| Открыть быстрый пульт | `/shoot` или `снять` |
| Проверить очередь | `/queue`, `статус` или кнопка `Очередь` |
| Посмотреть справку | `/help` |

`/shorts` без текста не придумывает тему: бот показывает готовые категории и истории. `/shorts SBER LKOH за год` ставит в очередь свой ролик по указанным тикерам и периоду. Рендер длинной истории или нескольких тикеров может идти несколько минут; следить за ним удобнее через `/queue`, `статус` или кнопку `Очередь`.

## Короткий вход

```text
/start
/shoot
снять
/help
/shorts
/shorts SBER LKOH за год
/draft metals
снять день
снять неделю
/queue
статус

LKOH
SBER LKOH 2020 2024
```

Если нужно несколько роликов, отправьте их одним сообщением: каждая непустая строка станет отдельной задачей. Можно писать обычным списком с `-`, `1.`, `1)` или `•` в начале строки.

```text
металлы
черновик угольщики
SBER LKOH 2020 2024 shorts
```

## Кнопки

Главное меню открывается через `/menu`, `/start` или `/меню`. Самые важные кнопки первого экрана:

- `День` и `Неделя` - готовые production-сценарии для публикации.
- `Top Studio` и `Случайный` - быстрый запуск готового сюжета без выбора.
- `Истории` - категории готовых сюжетов для Пульса; это тот же быстрый вход, что `/shorts` без текста.
- `Очередь` - активный job, ожидающие задачи и счетчики ошибок; используйте ее, если рендер идет долго.

Быстрый пульт открывается через `/quick`, `/shoot`, `снять` или `быстрый запуск` и показывает те же шесть действий. Посты, пакеты, музыку и обложки держите в `/guide`, `/posts`, `/music`, `/covers` и `kit <name>`.

`/shorts` без текста открывает выбор готовых историй по категориям. `/shorts SBER LKOH за год` ставит в очередь свой ролик по тикерам. `/help` показывает короткий вход, готовые истории, свой запрос и один пример инвестиционного ролика. Кнопки под справкой ведут к дню, неделе, историям, примерам, плану, шпаргалке, очереди и главному меню. `/guide` или `шпаргалка` показывает рабочий путь публикации без рендера.

После запуска ролика самые полезные кнопки - `Статус очереди`, `Меню` и варианты повтора: `Черновик 4s`, `Шортс 16s`, `12s`, `Aurora 16s`, `Studio 16s`, `Все темы x3`, `Пост`.

Кнопка `Примеры` открывает проверенные рецепты по металлам, российской новой экономике, US tech, крипте, MOEX futures и валюте. Там же есть быстрые действия `Случайный draft` и `Все draft`, чтобы быстро получить короткие проверочные ролики без ручного набора команд.

При старте бот обновляет встроенное меню команд Telegram. В клиенте Telegram должны быть видны только основные production-входы:

```text
/menu   главный пульт
/shoot  быстрый запуск
/shorts истории или свой запрос
/queue  статус очереди
/help   короткая справка
```

## Свой запрос

Формат:

```text
TICKER [TICKER...] [period] [market/source] [currency] [metric] [options]
```

Примеры:

```text
LKOH
SBER LKOH 2020 2024
SBER LKOH за 10 лет shorts
YDEX OZON за полгода shorts
сделай шортс про SBER и LKOH за полгода для Пульса
AAPL global USD shorts
BTC price duration=12 fps=24
SiH4 futures 2024 close
USD000UTSTOM selt 2024 close
```

Slash-вход добавляет режим к обычному запросу:

```text
/shorts SBER LKOH за год
/draft metals
```

`shorts` включает короткий ролик с `duration=16`, `fps=24` и `gradient`. `draft` делает быстрый черновик: `duration=4`, `fps=8`, без `gradient`.

## Инвестиции

Для сравнения регулярных вложений используйте `capital invest`, `initial`, `monthly` и валюту графика.

```text
gold silver palladium 2010-2026 RUB capital invest initial=0 monthly=30000 gradient
золото серебро палладий 2010-2026 RUB капитал с нуля ежемесячно 30к₽ gradient
```

Если график в `RUB`, ежемесячные взносы считаются в рублях. Если график в `USD`, взносы считаются в долларах. Линии на графике подписываются фактической суммой, нижние подписи по тикерам показывают проценты, а `Invested` внизу показывает фактически внесенную сумму.

## Готовые сценарии

Preset-сценарии нужны для быстрого контента в Пульсе без выбора тикеров с нуля:

```text
категории
category drama
category quiet
top quiet
random drama
черновик тихие
металлы
металлы студио
черновик угольщики
банки
дивиденды
телеком
ритейл
энергетика
стройка студио
top shorts studio
случайный шортс
```

Короткая production-шпаргалка:

| Хочу | Отправить в Telegram |
| --- | --- |
| Выбрать историю по настроению | `категории` |
| Менее хайповый российский сюжет | `category quiet` |
| Снять все тихие истории | `top quiet` |
| Скучный сектор связи | `телеком` |
| Потребительский ритейл | `ритейл` |
| Инфраструктурная энергетика | `энергетика` |
| Взять один случайный драматичный ролик | `random drama` |
| Быстро сделать draft тихих историй | `черновик тихие` |
| Просадки, памп/дамп, драму | `category drama` |
| Сырьевые циклы и металлы | `category commodities` |
| Истории роста и ожиданий | `category growth` |
| Недельный набор публикаций | `/publish_week` |
| Один готовый ролик дня | `/publish_day` |
| Пакет: хук, обложка, музыка, команды | `kit metals` |
| Текст поста без рендера | `post metals` |

Недельный production-план чередует разные типы историй: новая экономика, металлы, банки, связь, ритейл, энергетика и голубые фишки. Поэтому `/publish_day`, `/today_post` и `/publish_week` уже подмешивают менее хайповые российские сюжеты без ручного выбора.

Пакеты без немедленного рендера:

```text
/pack
/plan
/today_post
/week_posts
/kits
/posts
post metals
post LKOH SBER 2020 2024
```

`/pack` собирает top-сценарии, `контент-план` показывает недельную сетку, `пост дня` и `посты недели` отдают готовые тексты, а `kit metals` или `пакет металлы` открывают публикационный пакет одного preset. Внутри пакета есть готовые команды для ролика, черновика, Studio-варианта и поста.

## После рендера

После постановки задачи бот показывает job id и кнопку `Статус очереди`. Проверить состояние можно командой `/queue`, словом `статус` или кнопкой `Очередь`. Если рендер занимает несколько минут, бот присылает промежуточный статус `Рендер еще идет`, чтобы было понятно, что job не потерялся. После MP4 бот присылает готовый блок `Пост для Пульса (можно копировать)`: сначала чистый текст для публикации, затем отдельные варианты обложки и монтажные заметки с параметрами ролика. Под постом остаются быстрые кнопки для повторного варианта, очереди и возврата в меню.

Для preset-сценариев дополнительно есть ручной хук, хэштеги, музыка и кнопки для повторного запуска: `Черновик 4s`, `Шортс 16s`, `12s`, `Aurora 16s`, `Studio 16s`, `Все темы x3`, `Пост`, очередь и меню.

## Запуск бота

Создайте `.env` рядом с `pyproject.toml`:

```env
TELEGRAM_BOT_TOKEN=<botfather-token>
STOCK_PRICES_DEFAULT_ENGINE=stock
STOCK_PRICES_DEFAULT_MARKET=shares
STOCK_PRICES_CURRENCY=RUB
STOCK_PRICES_DURATION=30
STOCK_PRICES_FPS=20
```

Запуск локально:

```bash
stock-prices bot --allowed_chat_id 123456789
```

Постоянный запуск в Docker:

```bash
docker compose up -d --build
docker compose ps
```
