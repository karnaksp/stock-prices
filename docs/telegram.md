# Как писать запросы в Telegram

Бот не придумывает идеи сам и не использует LLM. Он принимает короткий текстовый запрос, ставит генерацию в очередь, загружает данные, рендерит MP4 и отправляет видео обратно в чат.

## Короткий вход

```text
/start
/shoot
снять
/help
/shorts SBER LKOH за год
/draft metals
снять день
снять неделю
/queue

LKOH
SBER LKOH 2020 2024
```

Если нужно несколько роликов, отправьте их одним сообщением: каждая непустая строка станет отдельной задачей.

```text
металлы
черновик угольщики
SBER LKOH 2020 2024 shorts
```

## Кнопки

Главное меню открывается через `/menu`, `/start` или `/меню`. Оно оставляет на первом экране только основные разделы:

- `Снять` - быстрый запуск частых действий.
- `Очередь` - активный job, ожидающие задачи и счетчики ошибок.
- `Контент-план` - недельная сетка публикаций.
- `Пакет Пульса` - top-сценарии, посты и batch-запуски.
- `Публикация дня` и `Неделя` - готовые production-сценарии.
- `Примеры`, `Пакеты`, `Тексты`, `Музыка`, `Шпаргалка`, `Справка` - вторичные разделы.

Быстрый пульт открывается через `/quick`, `/shoot`, `снять` или `быстрый запуск`. Он рассчитан на ежедневное производство: снять день, снять неделю, взять top-серию Studio, случайный ролик, пост дня, посты недели и очередь.

`/help` показывает короткий синтаксис в один экран. `/guide` или `шпаргалка` показывает рабочий путь публикации без рендера.

При старте бот обновляет встроенное меню команд Telegram. В клиенте Telegram должны быть видны только основные production-входы:

```text
/shoot        быстрый пульт для роликов
/publish_day  ролик дня и пакет поста
/publish_week 7 роликов на неделю
/shorts       ролик по запросу
/draft        быстрый черновик
/queue        статус очереди
/today_post   текст поста дня
/week_posts   посты недели
/help         короткая справка
```

## Свой запрос

Формат:

```text
TICKER [TICKER...] [period] [market/source] [currency] [metric] [options]
```

Примеры:

```text
LKOH
SBER LKOH 2020 2024
SBER LKOH за 10 лет shorts
YDEX OZON за полгода shorts
сделай шортс про SBER и LKOH за полгода для Пульса
AAPL global USD shorts
BTC price duration=12 fps=24
SiH4 futures 2024 close
USD000UTSTOM selt 2024 close
```

Slash-вход добавляет режим к обычному запросу:

```text
/shorts SBER LKOH за год
/draft metals
```

`shorts` включает короткий ролик с `duration=16`, `fps=24` и `gradient`. `draft` делает быстрый черновик: `duration=4`, `fps=8`, без `gradient`.

## Инвестиции

Для сравнения регулярных вложений используйте `capital invest`, `initial`, `monthly` и валюту графика.

```text
gold silver palladium 2010-2026 RUB capital invest initial=0 monthly=30000 gradient
```

Если график в `RUB`, ежемесячные взносы считаются в рублях. Если график в `USD`, взносы считаются в долларах. Линии на графике подписываются фактической суммой, нижние подписи по тикерам показывают проценты, а `Invested` внизу показывает фактически внесенную сумму.

## Готовые сценарии

Preset-сценарии нужны для быстрого контента в Пульсе без выбора тикеров с нуля:

```text
металлы
металлы студио
черновик угольщики
банки
дивиденды
стройка студио
top shorts studio
случайный шортс
```

Пакеты без немедленного рендера:

```text
/pack
/plan
/today_post
/week_posts
/kits
/posts
post metals
post LKOH SBER 2020 2024
```

`/pack` собирает top-сценарии, `контент-план` показывает недельную сетку, `пост дня` и `посты недели` отдают готовые тексты, а `kit metals` или `пакет металлы` открывают публикационный пакет одного preset.

## Параметры

```text
2020 2024              период с 2020-01-01 по 2024-12-31
2018-2026              короткий диапазон лет
from=2020-01-01        точная дата начала
to=2024-12-31          точная дата окончания
за 6 месяцев           относительный период
за год / за месяц      короткие относительные периоды
USD / RUB / EUR        валюта подписи и инвестиций
global / stock         источник и движок
shares / bonds / index рынок MOEX
futures / selt         MOEX futures или currency
close / price          цена закрытия
capital / reinvest     капитал с реинвестированием
initial=0              стартовая сумма
monthly=30000          ежемесячное пополнение
yearly=120000          ежегодное пополнение
gradient               градиентная линия
theme=studio           тема: default, aurora или studio
duration=12 fps=24     настройки видео
```

## После рендера

После постановки задачи бот показывает job id и кнопку `Статус очереди`. После MP4 бот присылает черновик текста для Пульса: заголовок, хук, идеи обложки, фактические параметры, вопрос для обсуждения и монтажное настроение.

Для preset-сценариев дополнительно есть ручной хук, хэштеги, музыка и кнопки для повторного запуска: draft 4s, shorts 16s, вариант 12s, Aurora и Studio.

## Запуск бота

Создайте `.env` рядом с `pyproject.toml`:

```env
TELEGRAM_BOT_TOKEN=<botfather-token>
STOCK_PRICES_DEFAULT_ENGINE=stock
STOCK_PRICES_DEFAULT_MARKET=shares
STOCK_PRICES_CURRENCY=RUB
STOCK_PRICES_DURATION=30
STOCK_PRICES_FPS=20
```

Запуск локально:

```bash
stock-prices bot --allowed_chat_id 123456789
```

Постоянный запуск в Docker:

```bash
docker compose up -d --build
docker compose ps
```
